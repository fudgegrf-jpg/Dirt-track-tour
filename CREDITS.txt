DIRT TRACK TOUR - credits and licenses
======================================

CODE, ART AND SOUND
  All game code, 3D models, textures, liveries and decals are made procedurally in this project's
  own code (js/). The race cars, haulers, tracks and scenery are built from code at run time.

  AUDIO: the primary car engine uses the permission-granted Jayden Fudge dyno recording
  credited below. Only that owned recording is sampled. The original Night12 V8 synthesizer
  remains the immediate/loading and decode/compatibility-failure fallback. Tire/dirt noise,
  crowd, wind, and the semi's diesel/jake brake remain procedural Web Audio synthesis.
  Private reference recordings are never embedded or shipped. WAV files in audio-samples/
  are legacy offline previews of the procedural synthesizer, not the current recorded engine.

  SPONSORS AND BRANDS: all sponsor, contingency, tire and fuel brand names on the cars are made up
  for this game. Any resemblance to a real company is unintended. Track names refer to real US
  venues for flavor only; the game is not affiliated with or endorsed by any track or sanctioning body.

V4 ORIGINAL V8 / STADIUM HARDWARE
  Pressure-pulse synthesis, deterministic firing variation, parametric EQ and
