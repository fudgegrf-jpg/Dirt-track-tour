DIRT TRACK TOUR - credits and licenses
======================================

CODE, ART AND SOUND
  All game code, 3D models, textures, liveries and decals are made procedurally in this project's
  own code (js/). The race cars, haulers, tracks and scenery are built from code at run time.

  AUDIO: every sound is synthesized live in code with the Web Audio API (js/audio.js):
  the V8 (firing-order pulse synthesis, intake/exhaust, valvetrain and gear whine),
  tire/dirt noise, crowd, wind, and the semi's diesel and jake brake.
  No audio recordings or third-party sound assets are used.
  The WAV files in audio-samples/ are offline renders of that same synthesizer, made for previewing.

  SPONSORS AND BRANDS: all sponsor, contingency, tire and fuel brand names on the cars are made up
  for this game. Any resemblance to a real company is unintended. Track names refer to real US
  venues for flavor only; the game is not affiliated with or endorsed by any track or sanctioning body.
