DIRT TRACK TOUR - late model dirt racing + team management + hauling across the US
==================================================================================

The game runs in your web browser (Chrome, Edge or Firefox recommended), but it has
to be served by a tiny local web server. Opening index.html directly will NOT work
(browsers block ES modules from file://).

WINDOWS
  1. Unzip this folder somewhere (e.g. Desktop).
  2. Double-click  play-windows.bat
     A black window opens and your browser goes to http://localhost:8080
     (refresh the page once if it loaded before the server was ready).
  3. Close the black window when you're done.
  Needs Python (python.org - tick "Add python.exe to PATH") or Node.js (nodejs.org).

MAC
  1. Unzip, then double-click  play-mac.command
     First time: macOS may say it's from an unidentified developer. Right-click the file >
     Open > Open. If it says "permission denied", open Terminal and run:
        chmod +x ~/Downloads/dirt-track-tour/play-mac.command
  2. Your browser opens http://localhost:8080. Close the Terminal window to stop.
  macOS ships with python3 (or it will offer to install the developer tools).

ANY OS (manual)
  Open a terminal in this folder and run ONE of:
     python3 -m http.server 8080        (Windows: py -m http.server 8080)
     npx serve -l 8080 .
  then browse to http://localhost:8080

CONTROLS
  Race:     W/Up throttle, S/Down brake (hold when stopped = reverse), A/D or Left/Right steer,
            C camera (chase / in-car / TV), R reset to track, P pause, M mute, G graphics quality, H driving guide
  Loading:  W creep forward, S brake/reverse, A/D steer, stop in the GREEN box on the trailer,
            X let the crew winch it ($300, slow), C camera
  Highway:  W throttle, S brake, A/D steer, Q cruise control, E take the truck-stop exit
            (right lane, near the EXIT sign), C camera (chase / cab / cinematic), P pause
  Shop & US map are point-and-click.
  Esc or P: pause menu (resume / settings / return to title). Settings (also on the title screen):
            volume, crowd, camera shake, graphics, default race camera (chase or in-car).
  Steering assist (Settings): Off / Low / Medium / High (new default) / Max. It smooths keyboard steering and
            gas, catches the car if it starts to swap ends, and keeps a slide controllable. You can still
            throttle-steer and slide the car; turn it to Low or Off once you have the feel.
  Controller: plug in any standard gamepad - left stick steer, RT gas, LT brake, Y camera,
            A/B/X actions, Start pause.

  AI difficulty (Settings): Easy / Normal (default) / Hard. Harder AI is faster, reads the track
            better, races you harder (slide jobs, crossovers, blocking) and makes fewer mistakes.
            Every AI driver has a personality: cushion slider, bottom-feeder, veteran, rookie, etc.
  Sound:    the V8, transmission, tires, crowd and semi (diesel + jake brake) are all synthesized live
            in code (no recordings). Sample WAVs rendered from the same engine are in audio-samples/.

Progress saves automatically between stages in your browser (localStorage).
Returning to title restarts the current race, loading attempt or highway leg.
If it runs slowly, press G in a race to lower graphics quality.

PHONE / TABLET PLAY
-------------------
Open the public HTTPS link in your phone's browser and rotate sideways. The game
waits while the rotate prompt is showing. First touch wakes the audio engine.
Touch devices default to Auto / Low graphics (512-pixel shadows, 450 dust particles,
0.85 render pixel ratio at normal phone DPR); a later graphics choice is retained.

Left: drag/rotate the analog wheel. Settings can switch to left/right arrows.
Right: hold GAS or BRAKE (keep holding when stopped to reverse).
Two fingers work together: steer while holding a pedal. Lifting one finger does
not release the other. Cancelled touches, pause and leaving the page release all
controls so nothing gets stuck.
Top buttons: Cam changes view, Pause opens the pause/settings menu, the square
icon requests fullscreen. Clear removes windshield mud; Reset recovers the car.
On the highway, Cruise toggles cruise control and Exit takes a signed truck-stop
exit (keep right and slow down). When loading, Winch uses $300 of game money.

Optional tilt: hold the phone comfortably and tap Tilt, then grant motion access
if iOS asks. The first motion reading calibrates your neutral position. Turn the
phone gently left/right. The steering wheel still overrides tilt while held. Tap
Touch to switch tilt off; toggle again to recalibrate. Motion requires HTTPS and
browser/device support; denied permission never disables touch steering.

Menus and settings scroll vertically with one finger. The shop's middle content
scrolls independently of its tabs and Go racing button. Driver/team inputs remain
editable. Phone-sized targets are at least 44 pixels high.

INSTALL / FULLSCREEN
Safari on iPhone: Share > Add to Home Screen, then launch the new icon. iPhone
Safari may not allow the regular Fullscreen API; the game explains the home-screen
option instead. Chrome/Android can use the fullscreen button or install shortcut.
The manifest includes landscape/fullscreen preferences and home-screen icons.
This is NOT an offline build: a live server/link is still required.

TEMPORARY PUBLIC LINKS
The account-free tunnel is separate from the zip. On this box, the prepared
/workspace/start-tunnel.sh starts/reuses a tunnel and prints its HTTPS address.
Anyone with that address can access the game. The release server exposes only
runtime assets, never .git, test/, reference/, screenshots/ or node_modules/.
The link dies if the tunnel, server, or box stops. Running the script after a
restart creates a new URL; an old installed shortcut must be replaced. If the
same tunnel is still running, rerunning the script keeps the current link.
No account, password, payment, or stored credentials are required.

serve.py is the release-only server with explicit JS, WASM and manifest MIME types:
  python3 serve.py --port 8080
For local development screenshot harnesses under test/, use a separate local-only
development server instead (for example python3 -m http.server 8092 --bind 127.0.0.1).
Do not expose the development server through a public tunnel.
