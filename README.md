# Dirt-track-tour

Mobile-ready Three.js dirt late model racing: five tracks, your team, and the miles between.

**Play:** https://raw.githack.com/fudgegrf-jpg/Dirt-track-tour/main/index.html

## Front end 02 / Classic 42
A clean dark/lime interface, hero-car showroom, focused driver/livery editor, garage Setup/Crew/Standings tabs, regional tour and road maps, persistent primary actions, and a clearer race debrief.

Your default driver is **Jayden Fudge #42**, with the selectable **Classic 42** paint: off-white sides, royal-blue nose/hood/roof, yellow outlined numbers, lime rocker trim and fictional contingency decals. The late-model body and driving physics are unchanged. Only untouched legacy Dale Rhodes/Jayden Fudge #21 red/white default profiles migrate; customized profiles stay yours. Migration preserves points, results, cash and crew. Edit the profile before starting a career to personalize your team and livery.

Phone: turn sideways. Steer on the left and hold GAS/BRAKE on the right. Optional tilt, camera, pause, fullscreen, cruise/exit and loading-winch controls appear for each stage. First touch unlocks audio. Phones start on Performance graphics.

Keyboard: WASD/arrows drive, C camera, P/Esc pause, H help. See START-HERE.txt and CREDITS.txt.

Fonts and icons are embedded; sound is synthesized. No install/build is needed. To play locally, serve this folder over HTTP. Raw.githack can cache branch updates for a few minutes and may show an “Open the page” confirmation before the game. A commit-pinned rawcdn.githack link avoids branch-version caching.
